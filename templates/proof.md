# proof.md

Copy this to `~/.claude/linkedin/proof.md`. These are the only numbers the
skills may put under your name. Anything else comes back as `{{your number}}`.

`/li-human` runs `provenance.py` on every draft and fails it if a number in it
is not on this page, not in the text being answered, and not confirmed by you
in chat.

One fact per line, optionally starting with the date it became true
(YYYY-MM-DD, which is ignored when checking). Write each fact the way you would
say it, with its unit, for example: proposal time went from X hours to Y
minutes; revenue grew X%; closed a $X contract.

This file has no numbers in it on purpose: every number here counts as proof.
Add your facts below this line.
